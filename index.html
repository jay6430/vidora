Everything you'd actually want

Pick the quality, pick the format, or just take the best available.

◈

Up to 4K, always with sound

2160p, 1440p, 1080p, 720p, 480p — whatever the video actually has. Every option comes out with the audio already in it.

⇄

MP4 or MKV, your choice

Defaults to MP4 so files play on any phone, TV or editor. Force either format when you need to.

♪

Audio-only downloads

Just want the track? One flag gives you the audio on its own as an M4A, no video attached.

◷

See the size before you commit

Each quality shows what it will cost you in megabytes, audio included — so 4K never surprises you.

☰

Subtitles and playlists

Burn in English subtitles when a video has them, or queue an entire playlist in one go.

⌘

Terminal or browser

Type one command, or open the visual picker in your browser. Works the same on macOS, Windows and Linux.

Set up once, use forever

Three copy-paste commands. No account, no subscription, no upload limits.

Windows
Linux
# install the dependencies $ brew install python ffmpeg # get Vidora $ git clone https://github.com/jay6430/vidora.git $ cd vidora $ pip install -r requirements.txt # use it $ python3 vidora.py "URL" # or the web UI $ streamlit run vidora_ui.py
:: install the dependencies > winget install Python.Python.3.12 > winget install Gyan.FFmpeg :: get Vidora > git clone https://github.com/jay6430/vidora.git > cd vidora > pip install -r requirements.txt :: use it > vidora.bat "URL" :: or the web UI > streamlit run vidora_ui.py
# install the dependencies $ sudo apt install python3 python3-pip ffmpeg # get Vidora $ git clone https://github.com/jay6430/vidora.git $ cd vidora $ pip install -r requirements.txt # use it $ ./vidora "URL" # or the web UI $ streamlit run vidora_ui.py
It runs on your computer, not a website. That is why there are no ads, no queues and no file size caps — but it also means you install it once rather than visiting a page. Downloading generally runs against a site's terms of service, so please use it for your own uploads, Creative Commons material, or content you have permission for.
