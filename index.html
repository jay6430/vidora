Set up in one step

Copy one line, paste it, press Enter. It installs everything for you and opens Vidora in your browser. No account, no subscription, no limits.

macOS
Windows
Linux
1

Open Terminal

Press ⌘ Space, type Terminal, press Enter. A window with text appears — that is all it is.

2

Paste this line and press Enter

curl -fsSL https://raw.githubusercontent.com/jay6430/vidora/main/install.sh | bash

Right-click to paste, or press ⌘ V.

3

Wait, then use it

It installs what it needs and opens Vidora in your browser. The first time takes a few minutes. After that it opens in seconds.

Download the installer

Double-click it

Windows may show a blue "Windows protected your PC" box, because the file was downloaded from the internet. Click More info, then Run anyway. This happens to every installer that is not commercially code-signed.

That is it

It installs Python and ffmpeg if you do not already have them, sets everything up, and opens Vidora in your browser. Takes a few minutes the first time. It also puts a Vidora icon on your Desktop — after this, just double-click that.

Opening it again later

On Windows, double-click the Vidora icon on your Desktop. On macOS and Linux, run the same line again — it remembers what is already installed and goes straight to opening the app.

It runs on your computer, not a website. That is why there are no ads, no queues and no file size caps — but it also means you install it once rather than visiting a page. Downloading generally runs against a site's terms of service, so please use it for your own uploads, Creative Commons material, or content you have permission for.
